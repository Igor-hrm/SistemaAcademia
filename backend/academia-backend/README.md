# Academia Backend

Back-end do Sistema de Gerenciamento da Academia de Milho Verde,
desenvolvido em Java com Maven.

## Estrutura do Projeto

### model

Contém as classes que representam as entidades do sistema,
como Cliente, Instrutor, Aula e Agendamento.

### dao

Responsável pelo acesso e pela persistência dos dados.

### service

Contém as regras de negócio do sistema.

### controller

Responsável por receber as requisições e encaminhá-las
para os serviços.

### config

Contém as configurações necessárias para o funcionamento
do sistema.

## Tecnologias

- Java
- Maven
- React (integração com o front-end)
